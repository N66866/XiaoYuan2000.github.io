# 实战二：MCP 工具箱 Agent

## 项目目标

构建一个能通过 MCP 调用外部工具的 Agent，例如查询 Git 仓库、读取项目文档、调用内部接口、生成报告。

## 功能范围

### 工具发现

Agent 能读取 MCP Server 暴露的工具列表、参数 Schema 和描述。

### 工具选择

根据用户任务选择合适工具，而不是把所有任务都交给模型文本生成。

### 工具执行

服务端负责权限校验、参数校验、超时控制和错误处理。

### 结果总结

把工具返回的结构化结果整理成用户可读的答案。

## 架构草图

### Host

提供用户交互入口和 Agent 执行环境。

### MCP Client

连接一个或多个 MCP Server，管理能力发现和调用。

### MCP Server

暴露本地文件、代码仓库、HTTP API、数据库只读查询等工具。

### Agent Runtime

负责规划、调用、观察、重试和结束。

## 关键小章

### 工具权限模型

不同用户只能看到和调用被授权的工具。

### 参数安全

模型生成参数后必须做白名单、路径范围、SQL 只读等校验。

### 错误恢复

工具失败时让模型解释失败原因，必要时尝试替代工具。

### 调用审计

记录谁在什么时候调用了什么工具，输入输出是什么。
