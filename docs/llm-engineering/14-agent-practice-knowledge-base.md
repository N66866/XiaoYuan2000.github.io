# 实战一：企业知识库问答 Agent

## 项目目标

构建一个能基于企业文档回答问题的 Agent，支持文档入库、语义检索、引用来源、资料不足拒答和多轮追问。

## 功能范围

### 文档管理

上传文档、解析文本、分块、生成向量、写入知识库。

### 问答链路

用户提问后，系统进行问题改写、检索、重排、上下文组装和答案生成。

### 引用来源

答案中标注使用了哪些文档片段，方便用户核对。

### 多轮追问

支持基于上一轮主题继续提问，但不能让历史消息污染新问题。

## 架构草图

### 后端模块

- 文档服务
- 分块服务
- Embedding 服务
- 检索服务
- Chat 服务
- 评测与日志服务

### 存储模块

- MySQL：知识库、文档、分块、任务状态。
- 向量库：Embedding 向量和检索字段。
- 对象存储：原始文件。

## 关键小章

### 入库状态机

设计上传中、解析中、分块中、向量化中、完成、失败等状态。

### 检索策略

先实现向量检索，再加入关键词检索、Rerank 和权限过滤。

### 答案生成 Prompt

要求模型只根据资料回答，资料不足时明确说明无法判断。

### 评测集

准备 FAQ、长文档问题、权限问题、资料不足问题。
