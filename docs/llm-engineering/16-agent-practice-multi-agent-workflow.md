# 实战三：多 Agent 工作流助手

## 项目目标

构建一个多 Agent 工作流助手，用规划 Agent、执行 Agent、审查 Agent 协作完成一个复杂任务，例如生成技术方案、代码审查报告或需求拆解。

## 功能范围

### 任务规划

规划 Agent 把用户目标拆成步骤、依赖和验收标准。

### 子任务执行

执行 Agent 根据计划调用工具、检索资料或生成内容。

### 结果审查

审查 Agent 检查事实依据、格式、遗漏项和风险。

### 汇总输出

总结 Agent 将多个中间结果整理成最终交付物。

## 架构草图

### Orchestrator

负责调度 Agent、维护状态、控制步骤上限和失败策略。

### Agent Pool

包含 Planner、Executor、Reviewer、Summarizer 等角色。

### Shared Context

保存任务目标、中间产物、工具结果、评审意见和最终结果。

### Trace Log

记录每个 Agent 的输入、输出、耗时、成本和工具调用。

## 关键小章

### 分工协议

每个 Agent 只负责自己的职责，避免多个 Agent 同时改同一份结果。

### 终止条件

设置最大轮次、最大成本、失败次数和人工接管条件。

### 质量门禁

审查 Agent 不直接改结果，而是给出问题清单和修改建议。

### 人工确认

涉及发布、删除、支付、通知等动作时必须人工确认。
