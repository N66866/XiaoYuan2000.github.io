# AgentScope 多智能体框架

## 这篇解决什么问题

AgentScope 是一个面向多智能体应用开发的框架。本篇先建立学习提纲：它适合什么场景、核心抽象是什么、如何组织多 Agent 协作。

## 适用场景

### 多角色协作

例如规划者、执行者、审查者、总结者共同完成任务。

### 仿真与评估

让多个 Agent 在受控环境中互动，用于策略测试和行为评估。

### 复杂工作流

把大任务拆给不同 Agent，每个 Agent 负责一个专业环节。

## 核心概念

### Agent

封装角色、模型、工具、记忆和行为逻辑。

### Message

Agent 之间传递的信息载体。

### Environment

管理交互场景、共享状态和外部反馈。

### Pipeline

组织 Agent 的执行顺序、分支和协作方式。

## 工程关注点

### 协作协议

多 Agent 需要明确谁发起、谁执行、谁评审、谁终止。

### 成本控制

多个 Agent 会放大 token、延迟和工具调用次数。

### 可观测性

需要记录每个 Agent 的输入输出和决策依据。
