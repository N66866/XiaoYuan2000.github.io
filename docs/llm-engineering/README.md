## 写作建议

每篇文章可以按同一套节奏扩展：

- 先解释这个概念解决什么问题。
- 再讲它在 LLM 应用架构中的位置。
- 然后补工程实现、风险点和选型判断。
- 最后放一个可运行或可落地的小案例。
